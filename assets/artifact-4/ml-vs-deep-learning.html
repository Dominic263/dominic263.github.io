Two Problems, Two Tools

Deep learning is not "better" machine learning — it is machine learning that does its own feature engineering. Knowing when that trade is worth making is the whole skill.

↓ Download the full report (PDF)

The most common misunderstanding about deep learning is that it sits at the top of a ladder — that traditional machine learning is the beginner's version and neural networks are what you graduate to. The real relationship is narrower and more useful than that. Deep learning is a subset of machine learning distinguished by one specific capability: it learns the features itself, directly from raw data, instead of being handed features a human chose.

That single difference is what the diagram below shows, and it drives every practical decision that follows — how much data you need, how much compute you'll spend, and whether you'll be able to explain the result to anyone.

The two cases from the report

The full report works through one real-world application of each approach and argues why swapping them would fail. In short:

Traditional ML · SVM

Customer churn prediction

Telecom and subscription providers scoring which customers are about to cancel, from structured account records.

  • Data already structured — the columns are the features
  • Modest data; trains in minutes on ordinary hardware
  • The reason drives the retention offer, so it must be explainable
  • Deep learning: no raw structure to exploit, more cost, no accuracy gain
Deep Learning · CNN

Diabetic retinopathy screening

Detecting a leading cause of preventable blindness from retinal photographs, where specialists are scarce.

  • Input is raw pixels — exactly what deep learning is for
  • Lesion patterns are too subtle and variable to hand-code
  • Large expertly graded image sets exist to learn from
  • Traditional ML: pixels as flat features lose all spatial meaning
The test I use: do the meaningful features already exist in the data, and can a person name them? If yes, traditional machine learning is almost certainly the right call. If the thing that matters is something experts recognize but cannot fully write down — a lesion, a face, the meaning of a sentence — that is when it is worth paying for deep learning.

The course lesson puts it well: traditional machine learning is like giving a student a checklist of what to look for; deep learning is like teaching the student to read and letting them work out from experience what matters. A checklist is faster, cheaper, and easier to audit — right up until the moment nobody can write the checklist.
